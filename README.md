# E-Commerce Frontend

## Overview

React app for an e-commerce storefront. Users can browse products, manage a cart, and place orders.

---

## Features

* Browse and search products
* Add/remove items from cart
* Checkout
* View orders
* Admin panel (manage products)

---

## Tech Stack

* React
* JavaScript
* CSS

---

## Setup

1. Install dependencies:
   npm install

2. Create `.env`:
   REACT_APP_API_URL=https://csci3916-final.onrender.com

3. Run:
   npm start

---

## Notes

* Uses session-based cart (no login)
* Built for demonstration purposes
